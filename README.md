# Quantum Archive

An open index of research bearing on when a quantum computer could run Shor's algorithm against RSA-2048: error correction, fault-tolerance overheads, hardware scaling, and resource estimates for factoring and discrete logarithms.

Each entry links to the paper at its source and records its DOI, licence, and the SHA-256 of the PDF that was read. The papers themselves are not stored here.
